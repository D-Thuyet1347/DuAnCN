# 📦 Thư Viện Thường Dùng Trong Dự Án ReactJS

Dưới đây là danh sách các thư viện phổ biến, thường được sử dụng khi phát triển ứng dụng ReactJS, kèm theo lệnh cài đặt.

---

## 🛠 Core Libraries

| Thư viện               | Lệnh cài đặt                             |
| ---------------------- | ---------------------------------------- |
| React Router           | `npm install react-router-dom`           |
| Axios                  | `npm install axios`                      |
| React Query (TanStack) | `npm install @tanstack/react-query`      |

---

## 🎨 UI Libraries

| Thư viện          | Lệnh cài đặt                                                               |
| ----------------- | -------------------------------------------------------------------------- |
| Tailwind CSS      | `npm install -D tailwindcss postcss autoprefixer`                          |
| Ant Design        | `npm install antd`                                                         |
| Material UI (MUI) | `npm install @mui/material @emotion/react @emotion/styled`                 |
| Icon              | `npm install react-icons --save`                 |
